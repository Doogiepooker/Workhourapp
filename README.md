# Workhour App

Simple browser app to track equipment hours on site.

## Features
- Save equipment entries with **unit number**, asset name, meter hours, date, and notes.
- Capture or attach a **site photo** for each entry.
- Persist records in browser local storage.
- Download data sheets as CSV or full backup as JSON.

## Run locally
```bash
python3 -m http.server 8000
```
Then open <http://localhost:8000>.
